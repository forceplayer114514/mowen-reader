# 墨问

一个支持 EPUB、PDF、TXT 的 AI 桌面阅读器：读有所思，问有所答。

## 下载安装

到 [Releases](../../releases) 页下载对应系统的安装包。

本项目未购买代码签名证书,首次打开需要手动放行一次。

### macOS

下载 `.dmg`,拖进「应用程序」,然后**右键点击应用图标,选「打开」**,在弹窗里再点一次「打开」。只需做这一次。

若提示「已损坏,无法打开」,在终端执行:

```bash
xattr -cr "/Applications/墨问.app"
```

### Windows

下载 `.exe` 运行。若出现蓝色的「Windows 已保护你的电脑」,点「更多信息」→「仍要运行」。

## 使用

1. 把 EPUB、PDF 或 TXT 文件拖进窗口，或点「添加书籍」，或点「扫描文件夹」批量导入
2. 点书的封面开始阅读
3. 左右方向键(或 PageUp / PageDown)翻页,顶部可以打开目录跳转章节
4. 书架和阅读页顶部都可以切换日间/夜间主题，阅读页还可以调整字号
5. 想删掉一本书,把鼠标移到封面卡片上,点右上角的「删除」,确认后会连同应用保存的本地文件副本一起删除,不可恢复

导入的书会复制一份到应用自己的数据目录,之后删除或移动原文件都不影响阅读。字号、主题和每本书读到的位置都会自动保存,下次打开接着读。

个人书库支持按书名或作者实时搜索；「继续阅读（书名）」直接打开最近读过的书，恢复已保存的位置，不受当前搜索影响。没有阅读记录时该按钮不可用。

书架可按「未开始 / 阅读中 / 已读完」筛选，按最近阅读、最近添加或书名排序。导入同一路径的已有书籍会提示重复；导入失败会显示对应文件名和原因。

封面左下角显示已读百分比，按最远读到的正文位置保存，不受字号或侧栏宽度影响；到达最后一页记为 100%，回翻不会撤销已读完状态。这是阅读位置进度，不验证是否逐页阅读。旧书的进度在再次打开时更新，不推算丢失的历史最远位置。

### 阅读统计

书架顶部点「统计」，查看今日、近 7 天、累计阅读时长和阅读日数；每日柱状图可切换近 7 / 30 天，悬停或点击查看当天时长。下方按单本书累计时长排列，点击继续阅读，支持日间 / 夜间模式。

统计同时显示书库平均进度、已读完（100%）的书籍数量，以及每本书的百分比进度条；删除书籍后不再计入书库统计。

可在统计页设置每日阅读目标（10 / 20 / 30 / 60 分钟），今日进度会随实际阅读时长更新；不设置目标也可以继续正常统计。

统计从本版开始记录，不推算历史阅读时间。仅在书本已显示、窗口位于前台且未闲置时计时；切换软件、最小化、锁屏、休眠或系统连续 5 分钟无操作会暂停。每 15 秒写入 SQLite，正常返回、关窗和退出会补存；强制终止或断电可能丢失最后约 15 秒。删除书籍会连带删除该书统计。

### 本地数据与升级

书籍、CFI 阅读位置、书签、注释、对话和消息按表保存在 SQLite `reader.db`，不是临时内存缓存。AI 回答每段先写盘再显示；中途关闭或异常退出后保留已收到的部分，不会自动续写。已提交的注释会保存，未提交的输入草稿不保证跨进程恢复。排版位置缓存损坏时重新生成，不清空书库或对话；保存失败会在界面提示。数据库升级在事务中完成，失败回滚，旧版软件拒绝打开未来版本的数据库。

安装新版会沿用原数据目录：macOS 为 `~/Library/Application Support/ai-reader`，Windows 为 `%APPDATA%/ai-reader`。如需手动备份，先彻底退出软件，再复制整个目录（包括 EPUB、封面和数据库文件），不要只复制数据库或删除旧目录。卸载时勿选择清除个人数据。

设置中的「云同步文件夹备份」可选择你自己的 iCloud、OneDrive、Dropbox 等同步目录，点「立即备份」生成包含数据库、书籍和封面的完整快照。墨问只保存到本地同步文件夹，云端上传由同步客户端完成；请确认云盘已同步完成。备份未加密，云盘服务可读取书籍、注释和对话，请只选信任的同步位置。API 密钥和可重新下载的离线翻译包、离线词典不包含在备份中。点「从备份恢复」选择备份文件夹，会先校验文件，恢复后自动重启；旧书库留在应用数据目录的「恢复前数据」文件夹中。

书架的「下载电子书」会进入内置在线书库（Z-Library）。在网站自行登录、选择 EPUB 并下载，完成校验后会自动加入默认书库，不弹出文件夹选择框；返回书架也不会打断下载。下载面板右上角「×」仅收起面板，返回书架时也会自动收起；点在线书库或书架上的「下载记录」可重新打开。可以关闭「下载后自动入库」，下载完再点「导入」。下载记录中可取消、移除或重试入库；相同文件重复下载不会重复添加。

支持 EPUB / PDF（64 MB 内）或 TXT（16 MB 内），最多保留 5 个待处理下载；MOBI / AZW3 / DRM 保护的书籍暂不支持。已完成但尚未入库的文件在应用重启后会恢复。网站使用独立沙箱和登录会话，不接触 AI 密钥或本地书库；网站自身的登录、验证码、域名及可用性由网站决定。如内置页面无法使用，可点「用浏览器打开」，再手动导入合法获取的书籍（外部浏览器下载不会自动入库）。

PDF 保留原版排版，显示实际页码，可缩放、按页跳转、读取文档目录，以及在有文字层的页面划选翻译、对话、加注释和书签。扫描/图片页可阅读，但暂不支持 OCR，页面会提示没有可提取文字；需要密码的 PDF 请先在 PDF 软件中解除密码。PDF 中的脚本、表单和外部链接不执行，字体、字符映射和渲染资源均随软件离线打包，不依赖 CDN。

TXT 支持 UTF-8、带 BOM 的 UTF-16 和常见中文 GB18030 编码；原始文本留存在书库，阅读时使用稳定的章节/段落结构转换为 EPUB，因此支持字号重排、阅读位置恢复、注释、书签和对话。自动识别常见“第…章”/“Chapter …”标题；没有标题的长文按段落拆分。导入其他编码前请先另存为 UTF-8。

EPUB / TXT 页脚的全书页码标为「约」，按固定正文位置估算，切换字号、行距或页边距后重算；旁边的「本章 x/y 屏」是当前排版的实测值，每翻一屏都会更新。PDF 页码则是文件的实际页码。

直接点击书籍封面、普通网页链接或下载链接会在内置页面打开，包括跨域书籍链接，不额外弹出放行确认；链接附带的点击广告脚本不执行。脚本自行弹窗、跳转到无关站点和站外重定向仍会被拦截；购物广告点「留在当前页面」即可。如网站的登录或下载确实需要额外跳转，确认目标后才点「允许并打开（本次）」；手动授权只在当前应用窗口内有效，直接点击不会永久加入域名白名单。站内菜单、锚点和 JS 专用控件保留网站行为；不支持在内置页面开多个标签页。此功能针对跳转和弹窗，不是全面过滤页面广告。HTTP 522 等错误属于网站服务器故障，应用会单独提示，不能通过放行拦截来修复。

### AI 对话

打开书后,右侧是对话侧边栏,可用标题栏按钮收起或展开。它会带上书名、作者和当前页正文;能读到目录和章节名时也会一并带上。无法精确取得可见文字时(例如合并范围跨章节),会改用第一份渲染章节的全文并明确标记为近似内容。侧边栏显示当前章节的历史对话;书架顶部的「对话」可按书本、章节管理所有记录。

在「设置」中填写接口地址、API 密钥和模型名,也可以修改系统提示词与上下文上限。常见 OpenAI 兼容服务商的填法:

书架的「对话」管理页支持搜索书名、章节、提问及回答，并可从对话直接定位原文。「摘录」按书和章节整理荧光笔、注释，支持搜索、定位原文及导出 Markdown；导出文件由本机保存对话框指定，不需要云端。

| 服务商 | 接口地址 | API 密钥 | 模型名 |
| --- | --- | --- | --- |
| OpenAI（[官方 API 文档](https://platform.openai.com/docs/api-reference)） | `https://api.openai.com/v1` | 你的 OpenAI API key | 填账号可用的模型 |
| DeepSeek（[官方文档](https://api-docs.deepseek.com/)） | `https://api.deepseek.com` | 你的 DeepSeek API key | 填账号当前可用的模型；文档中的型号会变化 |
| Ollama（[OpenAI 兼容文档](https://docs.ollama.com/api/openai-compatibility)） | `http://localhost:11434/v1` | 任意非空值，例如 `ollama` | 填本机已安装的模型 |

API 密钥只由主进程写入操作系统加密存储,不进数据库,也不会同步到其他地方。出于安全考虑,接口地址改变后必须重新填写密钥;远程接口需使用 HTTPS,本机回环地址可使用 HTTP。

拖选正文后松开鼠标即加入高亮,可同时选多段;点击引用可移除。发送时引用会随问题一起提交,发送后临时高亮会清除。对话按原文 CFI 位置保存,翻页或调整字号不会中断当前对话;翻回原文附近仍可找回旧记录。句子跨页时可点「合并下一页」临时并排查看,再翻页会收回双页。

上下文超限时按“目录缩为当前章节附近 → 删除最早问答 → 删除整个目录 → 仍超限则报错、不截断正文”的顺序裁剪。

#### 对话上下文如何管理

每次提问都会重新组装上下文，按顺序发送给设置中配置的模型服务：

1. **系统消息**：设置里的系统提示词、书名、作者（如有）、当前页正文。目录和当前章节名都能取得时，还会附上章节名及全书目录标题；目录不是各章节的正文。
2. **当前会话历史**：这条会话之前的问题、回答，以及每次提问时划选的原文。不会混入其他会话、注释或阅读统计。之前保存的翻译结果也会作为会话历史带上。
3. **本轮问题**：这次划选的所有引用句子和输入的问题。默认提示词要求优先围绕划选内容回答。

**翻页后继续同一会话**，当前页正文会换成新页面，之前的问答和引用仍保留；上一页未划选的完整正文不会自动再次发送。例如，第 10 页划选句子 A 并提问，翻到第 11 页追问时，模型会收到第 11 页正文、之前的句子 A 和问答，以及新的问题。聊天历史保存在本地，但每轮完整页面上下文不作为聊天记录保存。

通常只发送当前显示的正文，不自动上传整本书，也不搜索全书补充上下文。开启「合并下一页」时包含合并范围。EPUB / TXT 无法精确提取显示范围时，会退回当前渲染的第一份章节文档全文，并明确标记为近似内容；扫描 PDF 不会自动识别图片文字。

默认上下文上限为估算的 **8,000 tokens**，可在设置中修改，不会自动读取模型的实际容量。超限时先把目录缩到当前章节前后各 5 条，再逐轮移除最早的问答（不删除本地记录），然后移除目录；仍超限就提示错误。本轮问题、引用和正文不会被静默截断。默认的「不要剧透」是提示词约束，不保证模型绝不会剧透。

对话中的问题、引用、AI 回答及翻译结果都支持选中文字，并使用系统复制快捷键复制。

### 划选翻译与荧光笔

悬停右侧输入框上方的引用，点「翻译」即可翻译，无需配置 AI 密钥；译文保存在当前对话里，之后提问会带上译文。第一版支持英语→简体中文。设置中的「划选翻译」独立于 AI 对话配置：

- 在线查单词使用有道词典，显示音标和分条释义；整句仍使用免费 MyMemory。第一次使用需同意发送选中文字；只发送本次所选单词或句子，不发送整页、对话历史或 AI 密钥。免费接口可能受网络或配额限制。
- 离线查单词使用 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）的可选词库，约 63 MiB 原始下载量；离线译句仍使用 OPUS-MT 量化模型，约 117 MiB。两者分别下载、取消或删除；缺包或出错不会偷偷切回在线。译文下的喇叭朗读选中的原文，而非译文。

阅读页顶部点「荧光笔」，拖选句子即保存浅黄色高光；点「橡皮」后点击高光可整条擦除，并可撤销最近一次擦除。两种工具互斥，再点一次当前工具或按 Esc 回到普通划选。高光独立保存，字体、主题、侧栏布局或重启变化不会清空；橡皮不删除注释或聊天引用。

阅读页顶部的「朗读」使用操作系统自带声音朗读当前页，并在读完后自动翻页继续。可暂停、继续、停止、调整语速或选择系统已安装的声音；不上传正文，也不需要 API 密钥。扫描 PDF 没有文字层时无法朗读，跨章节且无法准确提取当前页文字时会提示翻页重试。

翻译成功后可点译文下的「收藏生词」；侧栏「生词」集中查看、定位和删除收藏。收藏只保存原文、位置与已有译文，不会再次请求翻译服务。阅读页的「搜索」或 Ctrl / ⌘ + F 可搜索书内正文并跳转命中；PDF 仅搜索有文字层的页面，定位到页。EPUB / TXT 还可在「排版」中调整行距、页边距和字体，PDF 保持原版式。点「快捷键」或按 ? 查看键位，可改目录与书签的单键快捷键。

### 原文注释

右侧栏可切换「对话 / 注释」。划选原文后，悬停下方引用，同时显示「翻译 / 注释」；点「注释」后输入想法并「提交」（也可用 Ctrl / ⌘ + Enter）。注释只保存在本地，不会发送给 AI 或加入聊天上下文。

正文末端的数字上标可点击查看、编辑注释；侧栏可选当页或全书范围，点击注释卡片或编号定位原文，删除需确认。当页列表按当前可见原文筛选（跨页注释也会显示），随翻页和字号变化更新。编号按全书原文顺序排列，新增或删除时更新；调整字号、切换主题或收起侧栏会重新定位上标，不插入正文、不改变原文定位。标签切换、翻页和收起侧栏保留未提交草稿；更换注释目标或返回书架前会提示放弃修改。目录里的书签可直接删除，无需先跳转到书签位置。

## 从源码运行

需要 Node 22.13 或更高版本。

```bash
npm install
npm run dev
```

其他命令:

```bash
npm test          # 单元测试
npm run test:e2e  # 端到端测试(需要图形环境)
npm run dist      # 打包出本机平台的安装包
```

## 已知问题

阅读所用的 epub.js(0.3.93)在每次成功渲染页面后都会往 `window` 上挂一个 `unload` 监听器,但从不移除;它的屏幕方向监听器还有一处大小写不一致的问题,导致想解绑时绑定的和实际调用的事件名对不上,解绑不掉。这两处都在库内部,应用这一层无法从外面把它们摘掉。实际影响是:如果一次运行中打开、切换了非常多本书,残留的监听器闭包会慢慢堆积,占用会缓慢增长。这不会导致崩溃或数据丢失,正常单本书或几本书的阅读会话感觉不到。

在线翻译依赖免费服务的网络可用性和配额；扫描 PDF 没有文字层时不能搜索、翻译或朗读其中的图片文字。云端备份依赖用户自己的同步客户端，墨问不直接连接云盘服务。
