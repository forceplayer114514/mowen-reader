# 墨问

一个带 AI 对话侧边栏的 EPUB 桌面阅读器：读有所思，问有所答。

## 下载安装

到 [Releases](../../releases) 页下载对应系统的安装包。

本项目未购买代码签名证书,首次打开需要手动放行一次。

### macOS

下载 `.dmg`,拖进「应用程序」,然后**右键点击应用图标,选「打开」**,在弹窗里再点一次「打开」。只需做这一次。

若提示「已损坏,无法打开」,在终端执行:

```bash
xattr -cr "/Applications/墨问.app"
```

### Windows

下载 `.exe` 运行。若出现蓝色的「Windows 已保护你的电脑」,点「更多信息」→「仍要运行」。

## 使用

1. 把 EPUB 文件拖进窗口,或点「添加 EPUB」,或点「扫描文件夹」批量导入
2. 点书的封面开始阅读
3. 左右方向键(或 PageUp / PageDown)翻页,顶部可以打开目录跳转章节
4. 书架和阅读页顶部都可以切换日间/夜间主题，阅读页还可以调整字号
5. 想删掉一本书,把鼠标移到封面卡片上,点右上角的「删除」,确认后会连同应用保存的本地文件副本一起删除,不可恢复

导入的书会复制一份到应用自己的数据目录,之后删除或移动原文件都不影响阅读。字号、主题和每本书读到的位置都会自动保存,下次打开接着读。

### 本地数据与升级

书籍、CFI 阅读位置、书签、注释、对话和消息按表保存在 SQLite `reader.db`，不是临时内存缓存。AI 回答每段先写盘再显示；中途关闭或异常退出后保留已收到的部分，不会自动续写。已提交的注释会保存，未提交的输入草稿不保证跨进程恢复。排版位置缓存损坏时重新生成，不清空书库或对话；保存失败会在界面提示。数据库升级在事务中完成，失败回滚，旧版软件拒绝打开未来版本的数据库。

安装新版会沿用原数据目录：macOS 为 `~/Library/Application Support/ai-reader`，Windows 为 `%APPDATA%/ai-reader`。如需手动备份，先彻底退出软件，再复制整个目录（包括 EPUB、封面和数据库文件），不要只复制数据库或删除旧目录。数据只保存在本机，卸载时勿选择清除个人数据；没有云端备份或跨设备同步。

书架的「下载电子书」会进入内置在线书库（Z-Library）。在网站自行登录、选择 EPUB 并下载，完成校验后会自动加入默认书库，不弹出文件夹选择框；返回书架也不会打断下载。下载面板右上角「×」仅收起面板，返回书架时也会自动收起；点在线书库或书架上的「下载记录」可重新打开。可以关闭「下载后自动入库」，下载完再点「导入」。下载记录中可取消、移除或重试入库；相同文件重复下载不会重复添加。

仅支持 64 MB 以内的 EPUB，最多保留 5 个待处理下载；PDF / MOBI 不会入库。已完成但尚未入库的文件在应用重启后会恢复。网站使用独立沙箱和登录会话，不接触 AI 密钥或本地书库；网站自身的登录、验证码、域名及可用性由网站决定。如内置页面无法使用，可点「用浏览器打开」，再手动导入合法获取的 EPUB（外部浏览器下载不会自动入库）。

直接点击书籍封面、普通网页链接或下载链接会在内置页面打开，包括跨域书籍链接，不额外弹出放行确认；链接附带的点击广告脚本不执行。脚本自行弹窗、跳转到无关站点和站外重定向仍会被拦截；购物广告点「留在当前页面」即可。如网站的登录或下载确实需要额外跳转，确认目标后才点「允许并打开（本次）」；手动授权只在当前应用窗口内有效，直接点击不会永久加入域名白名单。站内菜单、锚点和 JS 专用控件保留网站行为；不支持在内置页面开多个标签页。此功能针对跳转和弹窗，不是全面过滤页面广告。HTTP 522 等错误属于网站服务器故障，应用会单独提示，不能通过放行拦截来修复。

### AI 对话

打开书后,右侧是对话侧边栏,可用标题栏按钮收起或展开。它会带上书名、作者和当前页正文;能读到目录和章节名时也会一并带上。无法精确取得可见文字时(例如合并范围跨章节),会改用第一份渲染章节的全文并明确标记为近似内容。侧边栏显示当前章节的历史对话;书架顶部的「对话」可按书本、章节管理所有记录。

在「设置」中填写接口地址、API 密钥和模型名,也可以修改系统提示词与上下文上限。常见 OpenAI 兼容服务商的填法:

| 服务商 | 接口地址 | API 密钥 | 模型名 |
| --- | --- | --- | --- |
| OpenAI（[官方 API 文档](https://platform.openai.com/docs/api-reference)） | `https://api.openai.com/v1` | 你的 OpenAI API key | 填账号可用的模型 |
| DeepSeek（[官方文档](https://api-docs.deepseek.com/)） | `https://api.deepseek.com` | 你的 DeepSeek API key | 填账号当前可用的模型；文档中的型号会变化 |
| Ollama（[OpenAI 兼容文档](https://docs.ollama.com/api/openai-compatibility)） | `http://localhost:11434/v1` | 任意非空值，例如 `ollama` | 填本机已安装的模型 |

API 密钥只由主进程写入操作系统加密存储,不进数据库,也不会同步到其他地方。出于安全考虑,接口地址改变后必须重新填写密钥;远程接口需使用 HTTPS,本机回环地址可使用 HTTP。

拖选正文后松开鼠标即加入高亮,可同时选多段;点击引用可移除。发送时引用会随问题一起提交,发送后临时高亮会清除。对话按原文 CFI 位置保存,翻页或调整字号不会中断当前对话;翻回原文附近仍可找回旧记录。句子跨页时可点「合并下一页」临时并排查看,再翻页会收回双页。

上下文超限时按“目录缩为当前章节附近 → 删除最早问答 → 删除整个目录 → 仍超限则报错、不截断正文”的顺序裁剪。

### 原文注释

右侧栏可切换「对话 / 注释」。划选原文后，悬停下方引用，同时显示「翻译 / 注释」；点「注释」后输入想法并「提交」（也可用 Ctrl / ⌘ + Enter）。注释只保存在本地，不会发送给 AI 或加入聊天上下文。

正文末端的数字上标可点击查看、编辑注释；侧栏可选当页或全书范围，点击注释卡片或编号定位原文，删除需确认。当页列表按当前可见原文筛选（跨页注释也会显示），随翻页和字号变化更新。编号按全书原文顺序排列，新增或删除时更新；调整字号、切换主题或收起侧栏会重新定位上标，不插入正文、不改变原文定位。标签切换、翻页和收起侧栏保留未提交草稿；更换注释目标或返回书架前会提示放弃修改。目录里的书签可直接删除，无需先跳转到书签位置。

## 从源码运行

需要 Node 22.13 或更高版本。

```bash
npm install
npm run dev
```

其他命令:

```bash
npm test          # 单元测试
npm run test:e2e  # 端到端测试(需要图形环境)
npm run dist      # 打包出本机平台的安装包
```

## 已知问题

阅读所用的 epub.js(0.3.93)在每次成功渲染页面后都会往 `window` 上挂一个 `unload` 监听器,但从不移除;它的屏幕方向监听器还有一处大小写不一致的问题,导致想解绑时绑定的和实际调用的事件名对不上,解绑不掉。这两处都在库内部,应用这一层无法从外面把它们摘掉。实际影响是:如果一次运行中打开、切换了非常多本书,残留的监听器闭包会慢慢堆积,占用会缓慢增长。这不会导致崩溃或数据丢失,正常单本书或几本书的阅读会话感觉不到。

书架顶部的「对话」可按书本和章节查看、批量删除记录,目前还不能从管理页直接跳回原文或搜索对话。阅读侧栏中的章节历史可用「定位原文」回到对话位置。
