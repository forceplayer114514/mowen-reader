## 本次更新

- 优化 PDF 原版阅读：适合整页/宽度、清晰度与对比度增强、拖动页面、光标位置缩放，保留当前物理页和阅读中心。
- 扫描 PDF 支持本机按需 OCR：鼠标停留时后台准备文字层，也可直接拖选识别所选区域；无需先点识别按钮，不扫描整本书。
- 识别文字可直接引用、翻译、朗读、荧光笔高亮和加注释。修复中文拖选高亮碎裂、重复叠色及字框高度不齐。
- OCR 结果及 PDF 阅读中心结构化保存，重启、缩放、主题和侧栏切换不改变原文定位；结果随现有书库备份保存。
- 改善后台识别的取消、重试和快速切换处理，避免旧结果误入新页面或重复启动识别任务。

OCR 首次使用需下载中文/英文识别语言包；书页图片不上传。识别效果取决于原图质量，复杂多栏、公式和模糊小字可能不准，请核对原文。离线语言包不包含在书库备份中，可重新下载。

新版沿用原有数据目录，书籍、阅读位置、对话、注释和书签无需重新导入。安装前退出旧版即可。数据库升级后不建议直接降级；重要书库建议先使用设置中的备份功能。

验证：591 项单元测试、134 项端到端测试及构建通过；1 项真实离线翻译测试按原有条件跳过。三个平台的发布流程另执行离线翻译、打包运行时及打包 OCR 检查。
