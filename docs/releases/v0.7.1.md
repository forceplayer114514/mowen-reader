## 本次更新

修复 v0.7.0 整书翻译的两个实际问题，并把缓存从“按页”改为“按内容分句”：

- 落实下一页后台预取：本页译完且闲置时自动取下一页原文并翻译（EPUB/TXT 用同尺寸影子引擎独立翻页，主阅读页无闪烁、不污染阅读进度与对话；PDF 直接读下一物理页文本，不翻页不渲染）。下一页翻开即秒显。
- 翻回已译页面零请求：缓存以内容分句为记号，命中即复用，不再调用模型；下一页已译同样不请求。快速连翻时只保留最新一页排队（本页 + 下一页的 2 页窗口），绝不全书翻译。
- 改字号不重翻整书：分页变化只是分句的重新切片，迁移过来的分句直接复用，只翻译新露出的分句并拼接到本页译文中。
- 分句批量翻译：缺失分句按字符量装箱，一批一次模型调用（编号去、编号回，段数对不齐换更严格提示重试一次），上下文质量与调用次数兼顾。

数据说明：数据库升级到 v11，旧按页缓存表退役（其中的 v0.7.0 缓存无法迁移，升级后各页首次查看时重新翻译一次，之后永久复用）。书架按书独立开关、默认关闭、缓存永久保留随备份等其余行为不变。使用前仍需在设置里配好 AI 接口地址、模型名与 API 密钥。安装包未签名或公证，首次打开步骤见 [README](https://github.com/forceplayer114514/mowen-reader#下载安装)。

新版沿用原有数据目录，书籍、阅读位置、对话、注释和书签无需重新导入。安装前退出旧版即可。升级后不建议直接降级；重要书库建议先使用设置中的备份功能。

验证：607 项单元测试、139 项端到端测试（138 通过、1 项真实离线翻译按原有条件跳过）及构建通过；三个平台的发布流程另执行离线翻译、打包运行时及打包 OCR 检查。
