# 墨问 v0.5.0

- 更新彩色应用图标；名称和原有书库路径不变。
- 新增同步文件夹备份与恢复：可选择自己的 iCloud、OneDrive、Dropbox 等本地同步目录，不由墨问提供云端空间；恢复前保留旧书库副本。
- 新增书内搜索、摘录整理与导出、排版预设和可调整的快捷键。
- 新增系统语音朗读，可从页面中指定的位置开始；翻译结果的喇叭朗读选中的原文。
- 单词翻译改为词典卡片，显示音标与多条释义；在线查词无需 API 密钥。离线词典 ECDICT 可在设置中单独下载或删除。
- 原有 OPUS-MT 离线翻译包继续负责整句与段落翻译；词典与翻译包独立安装，设置页已说明各自用途。
- 新增生词收藏；对话、注释和阅读位置继续保存在本地。

## 升级与下载

新版继续使用原来的 `ai-reader` 数据目录，书籍、阅读位置、对话、注释和书签无需重新导入。建议安装前退出旧版并备份个人数据。可重新下载的离线模型和词典不包含在同步文件夹备份中。

macOS 请按 Apple 芯片或 Intel 选择 DMG；Windows 下载 x64 安装程序。安装包未签名或公证，首次打开的放行步骤见 README。
