## 本次更新

- 新增 AI 整书翻译：使用已配置的 AI 模型逐页翻译正文，译文覆盖在原页上方查看。
- 书架按书独立手动开启：每本书封面左上角「译·关 / 译·开」开关，默认关闭；开关只影响阅读页入口，已缓存的译文保留不删。
- 阅读页顶部操作：点「开始翻译」后只译本页，译完自动开始下一页（本页 + 下一页的 2 页窗口），绝不一次性翻译全书；「原文 / 译文」按钮随时切换查看。
- 翻页自动跟进：在译文视图下翻页，新页面命中缓存秒显，未命中自动翻译；翻译中的快速翻页只保留最新一页排队。
- 译文缓存永久保留：存于本地数据库，随书库备份一起保存，关闭、禁用、重开、升级均不删除；删书时随书级联清理。
- EPUB/TXT 按起点 CFI、PDF 按物理页码分别缓存；排版变化产生新页时旧缓存保留，命中即复用。

使用前需在设置里配好 AI 接口地址、模型名与 API 密钥（与 AI 对话同一套配置）；未配置时会明确提示去设置填写，不会静默失败。翻译按页计费，请留意模型用量。安装包未签名或公证，首次打开步骤见 [README](https://github.com/forceplayer114514/mowen-reader#下载安装)。

新版沿用原有数据目录，书籍、阅读位置、对话、注释和书签无需重新导入。安装前退出旧版即可。数据库升级到 v10（新增翻译开关与逐页缓存表，旧库自动迁移、默认关闭）；升级后不建议直接降级；重要书库建议先使用设置中的备份功能。

验证：599 项单元测试、138 项端到端测试（136 通过、1 项长跑偶发失败经单独重跑通过、1 项真实离线翻译按原有条件跳过）及构建通过；三个平台的发布流程另执行离线翻译、打包运行时及打包 OCR 检查。
