# 墨问 v0.4.0

- 书架封面左下角显示已读百分比；统计页增加书库平均进度、每本书的进度条和已读完数量。
- 进度按最远正文位置保存，不依赖字号或窗口排版；到达末页才显示 100%，回翻和重启保留已读完状态。
- 个人书库支持书名/作者搜索和「继续阅读（书名）」，恢复最近阅读的位置。
- 新增每日阅读时间图表、单本书时长排行；失焦、锁屏或闲置时暂停计时。
- 支持 EPUB、PDF 和 TXT；PDF 保持原始页码，TXT 支持常见中文编码。
- 划选翻译无需配置 AI 密钥：免费在线翻译或可选下载的离线模型；荧光笔与橡皮独立保存。
- 优化下载面板、注释和阅读位置持久化；修复在线书库正常链接被误拦截的问题。
- 修复 Intel Mac 离线翻译运行时缺失；Windows、Intel Mac、Apple 芯片 Mac 分别原生打包并验证安装包内离线推理。
- 更新 XML/ZIP 依赖的安全补丁。

## 升级说明

新版沿用原书库、阅读位置、注释、对话、书签和高亮，不需要重新导入。旧书的百分比在再次打开时按保存的正文位置更新，不推算过去未记录的最远阅读进度。进度表示读到的位置，不验证是否逐页阅读；时长统计从新版本开始记录，不估算历史时长。

macOS 下载对应芯片的 DMG，Windows 下载 x64 安装程序。安装包未签名/公证，首次打开的放行步骤见 README。建议升级前退出软件并备份完整个人数据目录。
