# PDF 原版阅读

## 本轮已实现

- PDF 自动进入原版阅读，复用阅读器、书签、对话和右侧栏，不新增独立页面。
- 专用工具条提供适合整页、适合宽度、缩放比例和拖动页面。PDF 字号与排版设置不适用，也不影响 EPUB/TXT 字号。
- 缩放和侧栏尺寸变化保留当前物理页及阅读中心；内容超出窗口时可以横向、纵向滚动。边缘位置受实际滚动范围约束。
- 拖动页面与文字选择互斥，Esc 返回文字选择；点选朗读起点会先返回文字选择。
- 页码使用 PDF 原始页数，缩放不重新分页。文字 PDF 的注释定位可滚动到对应文字。
- 没有文字层的页会提示限制，禁用句子高亮与朗读，不向用户声称助手能看到图片。仍可阅读、缩放、拖动和加书签。
- 显示偏好保存到独立的 `pdfView` 设置。扫描页阅读中心按书籍、物理页和归一化坐标存入 SQLite，返回书架和重启后恢复；视窗变化或边缘位置仍受实际滚动范围约束。
- PDF 绘制后以已解码图像显示，避开 Electron 中画布数据正常却不出画面的情况；文字层位置保持不变。翻页、失败和退出时释放临时图像地址。

## 按需 OCR

- 不提供手动识别按钮。鼠标在未识别的扫描页停留 350ms 后，本机后台准备本页文字层；直接拖选时自动识别所选区域，无需切换工具。打开/导入书不扫描整本书，也不阻塞阅读。工具条保留中文 + 英文或英文的语言选择。
- 使用 Tesseract.js 本机识别；首次操作下载固定版本语言包并校验本地缓存，书页图像不上传。离线语言包与识别结果不同：语言包存于 `ocr-models`，结果存于数据库并随现有书库备份保存。
- OCR 输入从原始 PDF 单页重新绘制，不依赖显示缩放、夜间滤镜和对比度，限制单次图像资源以避免大页耗尽内存。图书导入大小不受这一资源保护限制影响。
- 整页成功识别后在原图上原位增加透明选字层，不替换阅读 iframe、不重排书页，支持引用、翻译、朗读和句子标注。来不及准备时，区域识别结果直接进入现有对话栏的引用，取消大结果面板。横向拖选自动补足一行的裁剪高度。
- 透明选字层统一同行字框高度并补足正常字间空隙；选区、荧光笔和注释下划线合并重复矩形，避免中文拖选出现碎块和叠色。仅调整显示坐标，不更改 OCR 缓存的文字、顺序或已有定位。
- 后台整页识别进行中拖选，会保留最新选区并在文字层就绪后按坐标选中，不同时运行重复识别。进度、失败和取消以小型浮动提示显示，不改变阅读区尺寸。
- 识别任务可取消；Esc、翻出来源页、切书、退出和窗口销毁会取消任务或丢弃旧结果。等待旧任务清理后再开始新请求，防止工作线程争用。缩放不取消同一物理页的任务。
- 成功结果按书籍/物理页/语言及选区缓存。整页定位层和区域记录只追加不替换，保留既有文字位置；失败和空结果不缓存，允许重试。已有原生文字层不重复识别。
- 对比度使用原图/增强/较强/强四档，切换无需重新渲染；Ctrl/⌘ + 滚轮以光标所在位置缩放。按屏幕像素密度重新绘制，不能恢复扫描原图本身缺失的细节。

## 后续边界（尚未实现）

1. 原页面始终用于显示，识别结果不能替换或重排书页。已有可用文字层的页不重复识别。
2. 全书识别以后作为可取消、可恢复的后台任务；当前仅鼠标触发的可见页/拖选区域。
3. OCR 结果包含文字与对应矩形，作为透明交互层。复杂多栏、表格和公式不能承诺完全准确；请核对文字，当前不提供单独的识别校正面板。
4. 当前文字标注使用不可变缓存的 OCR 文字锚点。自由区域标注和页面旋转尚未提供；若以后加入，应以原始页与归一化矩形保存，不能绑定屏幕像素。
5. 缓存按书籍内容标识、物理页/区域、语言与识别引擎版本区分。失败不影响原图阅读；成功结果原子保存，下次复用。原文件、现有书签与对话不覆盖。

## 验收重点

- 用实际扫描书验证小字、横向页面、不同尺寸页和大图片。
- 放大后检查页面四边均可到达；切换整页/宽度，拖动，再收起和展开侧栏，不跳页。
- 快速重复点击缩放仍逐次生效；聚焦缩放下拉框操作键盘不误翻书页。
- 文字 PDF 的划选、注释、高亮、定位和重启恢复仍正常。
- 两种主题、900×600 最小窗口均保持控件可用。
- 回归测试读取实际窗口截图像素，不能只验证画布内部数据，以免空白页面被误判为正常。
